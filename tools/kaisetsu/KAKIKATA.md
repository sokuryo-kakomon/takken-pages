# 解説の書き方（宅建 過去問ドリル）

## 基準
- **法令の基準日は 2026年4月1日施行の法令**（令和8年度試験の基準）。出題当時と今で答えが変わる肢・問は、`notice` に「改正」の札を書き、今の法令での答えを先に書く。正解番号そのものは RETIO の公表どおり（変えない）。
  - 例: `"notice": "法改正の注意：令和6年4月施行の改正で〇〇が△△になったため、今の法令では肢2も正しい。出題当時の正解は3。"`
- 2025年4月〜2026年4月の間に施行された改正に特に注意する（例: 区分所有法の改正、不動産登記法の住所等変更登記の義務化、民法の親権・養育費等の改正、建築基準法の改正 など）。当たるかどうか分からないときは `doubts` に書く。
  - 確かめ済みの改正の例: 不動産取得税の免税点は 2026-04-01 以後の取得から 土地16万円・建築による家屋1戸66万円・その他の家屋1戸34万円（旧 10万・23万・12万。地方税法第73条の15の2第1項）。新築住宅の1,200万円控除（地方税法第73条の14第1項）の床面積は 2026-04-01 から 40m2以上240m2以下（旧 50m2〔貸家40m2〕以上。地方税法施行令第37条の16、令和8年政令第83号。東京23区の特定都市再生緊急整備地域は令和13年3月31日まで旧の下限）。民法第306条の一般の先取特権に「子の監護の費用」が入った（2026-04）。報酬告示は令和6年7月の改正で番号が変わった（広告料金のただし書は第11①）。懲役・禁錮は 2025-06 から拘禁刑。区分所有法は 2026-04-01 の改正で、普通決議（第39条第1項）が「出席した区分所有者（議決権を有しないものを除く）及びその議決権の各過半数」に、管理組合法人の設立（第47条第1項）が「過半数かつ議決権の過半数を持つ者が出席し、出席者の各4分の3以上」になった。共用部分の重大変更（第17条第1項）も出席者基準の各4分の3以上（規約で2分の1超まで下げられる）になり、旧「区分所有者の定数だけ規約で過半数まで減らせる」は無くなった。ほかの特別決議・招集・規約の条も「議決権を有しないものを除く」などが入っているので、区分所有法の問は必ず今の版で条文を引く。宅建業者名簿（宅建業法第8条第2項）は 2025-04-01 施行の改正（令和6年法律第53号）で「第4条第1項各号（第5号を除く）」などになり、専任の宅建士の氏名は名簿の登載事項から外れた。ただし変更の届出（第9条、第4条第1項第1号〜第5号）には専任の宅建士の変更も今も入り、30日以内に届け出る。閲覧（第10条）は名簿と特定書類に絞られた。
- 条文を確かめるときは e-Gov の API v2 で日付を付けて引く: `https://laws.e-gov.go.jp/api/2/law_data/<法令ID>?law_full_text_format=xml&asof=2026-04-01`（law_full_text は base64 の XML）。旧い v1 は今の版を返さないことがある。
- 施行令・施行規則・告示の条番号も算用数字で書いてよい（「建築基準法施行令第25条」。画面は施行令・規則の後をリンクしないので、法律の条と取り違えない）。
- 判例の日付は確かなものだけ。確かめられなければ「判例」とだけ書く。
- 根拠は条文番号（「民法第545条第1項」のように **第◯条** の形で書く。画面で e-Gov へのリンクになる）と判例（「最判平7.9.19」のように）。条番号に自信がないときは書かずに `doubts` へ。

## 文
- **自分の言葉で書く。** 参考サイトの解説文を写さない・言い換えだけの書き直しもしない（後で 8字の連なりで機械照合する）。参考サイトから使ってよいのは「答え」と「各肢の正誤」だけ（入力の `site_verdicts`）。
- だ・である調。1肢 1〜4文。結論（正しい／誤り）の理由を、どこが・なぜで書く。
- 問題文の引き写しは最小限に（肢を言い直すのではなく、理由を書く）。
- 宅建業法の問では「宅建業者」「宅建士」と略してよい（解説の中だけ）。
